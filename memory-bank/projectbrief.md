# Project Brief: ISICECAKEOISIS INC. // Business-to-Agent (B2A) Systems Architecture

## Core Goals
- Modularize the monolithic single-file application into a production-grade, maintainable React + TypeScript architecture.
- Showcase the comprehensive Business-to-Agent (B2A) systems architecture founded by Michael Scott Hoyt (@hoytnix).
- Present the 9 snap-scroll viewports covering Goomba origin, investment thesis, flagship Yuli AI character SDK, Aevloc NFC + SaaS, Purple Canary harm reduction lab, structured lore canon, machine commons (/llms.txt), accredited investor inquiries, and the 6 sibling ecosystem hubs.

## Scope
- Frontend: React 19, TypeScript, Tailwind CSS v4, Lucide React icons, modular SVG diagram simulations.
- Backend: Express server with direct `/llms.txt` route, investor inquiry ingestion, and Gemini AI endpoints.
- Modularity: Separated concerns across layout, individual slides, interactive diagrams, modals, types, and ecosystem data.
